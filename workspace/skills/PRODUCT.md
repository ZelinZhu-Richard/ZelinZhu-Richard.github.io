## Product Purpose

A shareable collection of Richard Zhu's AI agent skills, integrated into his personal portfolio at /skills/.

## Users

Portfolio visitors who want to find skills Richard uses and understand the skills he creates.

## Capabilities and Constraints

- “Skills I use” entries have a one-sentence description and a link to the original GitHub repository.
- “Skills I create” entries will link to /skills/xxx/ pages covering purpose, design, testing, and usage.
- SkillSpector by NVIDIA is the first user-supplied entry. No authored skills have been supplied yet.
- Keep actual skill development in its separate project. This repository provides the showcase.
- Reuse the existing static build, shared portfolio frame, fonts, and styles.
- Keep all work under the project workspace; do not inspect protected data.
